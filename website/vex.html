Read the evidence in context

This navigator covers published VEX statements, not the complete library catalog. Latest means the highest OSERA tag number within each version prefix and supplier represented in this VEX feed, not the highest upstream version or necessarily the newest catalog release. Other version schemes remain visible. A “fixed” status applies to the named vulnerability on the exact product version. Missing statements do not mean a library is unaffected or vulnerability-free.

The fix list shows coverage reported for the selected release, including carried-forward fixes declared for that artifact. It is not just the changes introduced in that tag. We use the selected version’s VEX evidence rather than combining historical statements; “new since the previous release” requires release evidence that distinguishes new and carried-forward fixes.

Library counts use package identities without versions. Patched entries count distinct vulnerability × artifact pairs with a published “fixed” status; distinct CVEs count CVE identifiers across fixed statements. Each view uses its source’s publication time, which may differ from the homepage metrics.
